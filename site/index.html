GoLisDo

Sua música sempre ao alcance.

GoLisDo é um aplicativo para Windows com controles compactos de mídia. O GoLisDo WebPlayerControl conecta players web compatíveis ao aplicativo instalado no computador.

Política de Privacidade Suporte público

Integração local

A extensão WebPlayerControl comunica-se com o aplicativo GoLisDo instalado no Windows por Native Messaging.

Players compatíveis

Integração com YouTube Music, YouTube, Spotify Web e Deezer Web, conforme os recursos disponíveis em cada serviço.

Privacidade

O projeto não possui backend próprio para coletar dados de reprodução da extensão.
