GoLisDo WebPlayerControl — test access

Reviewer build: GoLisDo 0.6.6 · Extension 0.1.53

This page provides the Windows companion app and the steps required to test the main functionality of the GoLisDo WebPlayerControl Chrome extension.

The extension is a companion to the GoLisDo Windows app. Full testing requires the Windows app to be installed because the extension communicates locally with it through Chrome Native Messaging.

1. Download the Windows reviewer build

Download GoLisDo 0.6.6 for review

File: GoLisDo-Setup-x64.exe

SHA-256: A583A51EA5ED3E2B79DF0F1DB036CD75A06E1A970BC6DC95F384503358B2E1D6

2. Install GoLisDo

  1. Run GoLisDo-Setup-x64.exe.
  2. Complete the installer using the default options.
  3. Launch GoLisDo after installation.

The installer registers the Native Messaging host required by the browser extension.

3. Install the extension under review

Install the submitted GoLisDo WebPlayerControl build through the Chrome Web Store review environment. No GoLisDo account, username or password is required.

4. Test the connection

  1. Open the extension popup.
  2. With GoLisDo running, the popup should report that it is connected to GoLisDo.
  3. Open one of the supported web players: YouTube Music, YouTube, Spotify Web or Deezer Web.
  4. Start media playback.
  5. GoLisDo should display the current media metadata and playback state.

5. Test media controls

From GoLisDo, test the controls supported by the active provider, such as:

  • play and pause;
  • previous and next track;
  • volume and mute;
  • playback position when supported;
  • the “Up next” queue and queue selection when supported by the provider.

6. Supported origins

  • https://music.youtube.com/*
  • https://www.youtube.com/*
  • https://open.spotify.com/*
  • https://www.deezer.com/*

7. Data and network behavior

The extension communicates with the GoLisDo Windows companion app locally through Chrome Native Messaging. The extension does not require a GoLisDo backend account and does not send playback metadata to a developer-operated backend.
